## 2. 夜间奶后哭闹 SOP（待验证草案）
初衷：尽量采用适当、温和的安抚方式，避免过度干预。

1. 首先排查危险信号及急需处理的异常情况。
2. 观察饥饿线索、检查是否喝饱，结合全天摄入情况和宝宝表现判断。
3. 尝试语言安抚、轻柔接触。
4. 按宝宝反应轻拍、抱起安抚，喂奶后有需要时尝试拍嗝。
5. 记录每一步的时间、效果、是否复发，并复盘。

**安全边界**：不要强行要求宝宝在抱起前持续哭泣；避免剧烈摇晃及用力按压腹部。持续难以安抚、发热、呼吸异常、反应差或吃奶明显变差等应及时联系医疗人员。

## 3. 产品核心洞察（假设）
宝宝是一个不断变化、多个系统彼此影响的个体。评估状态不能只观察单一变量，应把喂养、体重增长、睡眠、哭闹、排便、尿量、精神状态等放在上下文中综合判断。

### 示例：“奶瓣便便”
- **事实**：便便有颗粒状外观。
- **待验证假设**：部分婴儿的这种外观可以属于正常便便变化。
- **不可直接推断**：仅凭外观不能确认消化不良，也不能判定是蛋白质或脂肪未被完全消化。
- **分析需补充**：月龄、奶种、24 小时总奶量、排便变化、尿量、体重增长趋势和精神状态。

### 与传统记录类 App 的差异化假设
现有部分产品更重数据记录而非综合解释与干预效果验证。目标是从“单项记录”升级为：

**记录 → 多指标关联 → 医学证据约束的辅助解释 → 护理动作 → 效果反馈 → 更新个体基线**。

需通过竞品调研与真实评测验证这个差异是否成立。

## 4. 拟增加的数据指标
- 状态：哭、睡、醒；起止时间。
- 喂养：单次奶量、频率、全天总量。
- 护理：屁屁清洗、纸尿裤、安抚方式。
- 哭闹事件：时长、情境、严重程度、干预效果。
- 成长：体重、增长趋势。
- 排便：次数、颜色、性状及变化。

## 5. 候选分析功能
1. **便便辅助观察**：图像描述 + 既往记录 + 风险提示 + 可追溯证据。
2. **头型趋势记录**：标准化拍照、时间对比、就医提示；不能替代临床诊断。
3. **哭闹分析**：探索与喂养、睡眠、护理行为的时间关联，不将相关性误当因果。
4. **护理知识支持**：优先参考 AAP 等机构公开指南的可引用信息，维护证据来源、适用月龄、条件与更新日期，避免直接复制受版权保护内容。
