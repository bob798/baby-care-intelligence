# Baby Care Intelligence

An evidence-grounded infant care observation and decision-support research project.

## Research logs

Daily product observations are stored in `docs/daily/`. Public logs contain no identifying health records.

## Principles

- Track longitudinal patterns instead of interpreting a single observation in isolation.
- Separate observed facts, hypotheses, and verified medical guidance.
- Keep personal health information private.
- Treat AI insights as decision support, not diagnosis.
